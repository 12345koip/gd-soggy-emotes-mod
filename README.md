## Soggy Emotes!

A mod for Geometry Dash that adds 6 pictures of the soggy cat as emote options.

New emotes:
- **:soggy:**
- **:soggy_cup:**
- **:soggy_dry:**
- **:soggy_fear:**
- **:soggy_sniff:**
- **:soggy_what:**

This mod is local. Other players won't see the soggy emotes unless they also have this mod installed.
